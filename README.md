# Excel Data Analysis Project – Sales Performance Dashboard

## 📌 Project Overview

This project demonstrates the use of Microsoft Excel for data analysis, statistical analysis, customer segmentation, and business reporting.

Using a sales dataset containing 200 transactions, I applied various Excel functions and analytical techniques to transform raw data into meaningful business insights.

The project focuses on analysing sales performance, understanding customer behaviour, identifying trends, and presenting key findings through charts and an interactive dashboard.

## 🎯 Project Objectives

- Analyse sales and profit performance.
- Apply Excel formulas and advanced functions.
- Perform statistical and regression analysis.
- Identify high-value customers.
- Analyse sales trends across regions, categories, and time periods.
- Create Pivot Tables and visualisations.
- Build a dashboard to communicate important business insights.
- Convert analytical findings into actionable business recommendations.

## 🛠️ Excel Features & Concepts Used

### 1. Excel Formulas and Functions

- `SUMIF()` – Calculates total sales based on conditions.
- `COUNTIF()` – Counts transactions matching specific criteria.
- `AVERAGEIF()` – Calculates conditional averages.
- `IF()` – Performs logical tests.
- `RANK()` – Ranks customers based on sales.
- `INDEX()` and `MATCH()` – Retrieves information from tables.
- `LARGE()` – Finds the largest values.
- `PERCENTILE()` – Calculates customer segmentation thresholds.
- `SUM()` – Calculates totals.
- `AVERAGE()` – Calculates averages.
- `MEDIAN()` and `MODE()` – Measures central tendency.
- `STDEV()` and `VAR()` – Measures data variation.
- `NOW()` and `TODAY()` – Handles date and time values.
- `LINEST()` – Performs linear regression calculations.
- `GROUPBY()` – Groups and summarises data in supported Excel versions.

## 📊 Key Business Insights

The analysis generated several useful findings:

- **Total Sales:** Approximately ₹195,217.76
- **Total Profit:** Approximately ₹68,287.01
- **Total Transactions:** 200
- **Profit Margin:** Approximately 35.0%
- **Leading Region:** West, contributing approximately 22.6% of sales.
- **Top Product Category:** Books, contributing approximately 24.1% of sales.
- **Top Customer:** CUST015, with approximately ₹11,611.06 in sales.
- **Top 10 Customers:** Contribute approximately 47.3% of total sales.
- **Regression R-squared:** Approximately 59.82%, indicating the proportion of Profit variation explained by Sales in the fitted linear model.

These findings help demonstrate how Excel can be used to understand business performance and support data-driven decisions.
